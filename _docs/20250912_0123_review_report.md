## ルール詳細（暫定）
- `<content>`
  - `url`: 必須, 型=`url`（`http(s)://...` か `/` で始まる絶対パスを許容）
- `<permits>`, `<prohibits>`
  - `type`: 必須, 列挙={usage, distribution, modification, private-use}
- `<amount>`（将来のための下地）
  - `currency`: 必須, 型=`iso4217`（大文字3文字）
